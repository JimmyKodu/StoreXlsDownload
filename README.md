# StoreXlsDownload

一个用于拦截和管理 XLS 文件下载的 Chrome 扩展程序。

## 功能特性

- 🎯 自动拦截 XLS/XLSX/XLSM/XLSB 文件下载
- 📊 存储下载历史记录（最多100个）
- 🔍 搜索已保存的文件
- 📱 简洁美观的用户界面
- 🔗 可以重新打开已下载的文件
- 🗑️ 支持删除单个或所有记录
- 🔢 显示已拦截文件数量的徽章

## 安装方法

### 开发者模式安装

1. 下载或克隆此仓库到本地
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`
3. 在右上角启用"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择包含 `manifest.json` 文件的项目文件夹
6. 扩展程序已成功安装！

## 使用说明

1. **自动拦截**：当您尝试下载 XLS 文件时，扩展会自动记录下载信息
2. **查看记录**：点击浏览器工具栏中的扩展图标查看所有拦截的文件
3. **重新打开**：点击文件条目或🔗按钮在新标签页中打开文件
4. **搜索文件**：使用搜索栏按文件名或URL筛选文件
5. **删除记录**：点击🗑️按钮删除单个记录，或点击"清空所有"删除所有记录

## 技术说明

- 使用 Manifest V3 标准
- 使用 Chrome Downloads API 拦截下载
- 使用 Chrome Storage API 本地存储数据
- 支持的文件类型：.xls, .xlsx, .xlsm, .xlsb

## 权限说明

- `downloads`：用于监听和拦截下载事件
- `storage`：用于本地存储下载记录

## 隐私保护

- 所有数据仅存储在本地浏览器中
- 不会上传任何数据到远程服务器
- 用户可以随时清空所有记录
